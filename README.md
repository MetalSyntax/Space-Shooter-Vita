A pixel-art space shooter for PS Vita, written in C++17. It is a native port of **Space Shooter Remastered** (Phaser 3) with the same campaign, ships, enemies and bosses. Every sprite and every sound is generated by code at startup: the game ships with no image or audio files.

## Features

- **10-sector campaign** with autosave, 3 difficulty levels and a perk choice after each sector.
- **5 ships** with their own stats and ability: Vanguard, Striker, Phantom, Bulwark and Nova.
- **10 bosses**, each with its own state machine: telegraphed beams, turrets, shield orbs, decoys, kamikaze swarms, a gravity vortex and a 3-phase final boss.
- **Full enemy roster**, where color means ability: aimed fire, spread fan, ram dash, splitting, laser beam, bubble shield and teleport.
- **Combos, critical hits and 7 power-ups**: shield, rapid fire, spread, missiles, drone, magnet and Hyper Bomb.
- **All screens from the original**: main menu, Hangar, Guide, Pause, Sector Cleared, Game Over and Victory with local high scores.
- **Procedural audio**: sequenced music (menu, per-sector combat tempo, jingles) and synthesized sound effects.
- **Spanish and English**, using the Press Start 2P pixel font.
- **Native 960×544 at 60 FPS**, with both analog sticks used as a twin-stick shooter.

## Controls

| Action | In game | In menus |
|---|---|---|
| Move / navigate | Left stick or D-pad | Left stick or D-pad |
| Aim | Right stick | — |
| Fire / confirm | R or Cross | Cross |
| Hyper Bomb / back | Square or Circle | Circle |
| Pause | Start | Start (main menu: play) |
| Switch tab | — | L / R (Guide) |

On desktop: WASD/arrows to move, IJKL to aim, Space to fire, X/B for Hyper Bomb, Esc/P to pause, Enter to confirm, Q/E to switch tabs. SDL game controllers work too.

## Install

1. Download `ShooterSpace.vpk` from the [Releases](../../releases) page.
2. Copy it to your PS Vita and install it with VitaShell.
3. Launch **Shooter Space** from the LiveArea.

Progress, high scores, settings and trophies are saved to `ux0:data/shooterspace/save.dat`.

## Building

### PS Vita

Requires [VitaSDK](https://vitasdk.org/). vitaGL and vitaShaRK are git submodules in `lib/`; vitaGL is built with `patches/vitagl-disable-system-app-mode.patch` applied, which keeps the LiveArea build out of system-app mode (that mode causes a black screen).

```sh
git submodule update --init
cd lib/vitagl && git apply ../../patches/vitagl-disable-system-app-mode.patch && cd ../..
# build libvitaGL.a and libvitashark.a inside lib/ following their READMEs, then:
cmake -S . -B build_vita
cmake --build build_vita -j8
# Output: build_vita/ShooterSpace.vpk
```

### Desktop (macOS / Linux)

Requires SDL2 and pkg-config.

```sh
cmake -S . -B build
cmake --build build -j8
./build/ShooterSpace   # the game
./build/selfcheck      # campaign/score rule checks
```

## Project layout

| Path | Contents |
|---|---|
| `src/scenes/GameScene.cpp` | Player, combat, power-ups, effects and HUD |
| `src/scenes/Enemies.cpp` | Enemy roster and wave director |
| `src/scenes/Boss.cpp` | Boss state machine and the 10 boss behaviors |
| `src/scenes/Menus.cpp` | Main menu, Hangar, Guide, Pause, Sector Cleared, Game Over and Victory |
| `src/generators/` | Procedural pixel-art generators and the original sprites |
| `src/Assets.cpp` | Bakes every texture at startup |
| `src/audio/Synth.cpp` | Synthesizer and music sequencer |
| `src/Renderer.cpp` | vitaGL renderer (SDL2 renderer on desktop) |
| `include/FontData.hpp` | 8×8 font atlas generated from `assets/PressStart2P-Regular.ttf` |
| `sce_sys/` | LiveArea assets (all PNGs must be 8-bit indexed) |
